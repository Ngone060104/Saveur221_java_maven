# Saveur 221 - Application Java Console

Application Java Console destinée au personnel interne
du restaurant Saveur 221.

## Technologies

- Java 17
- Maven
- PostgreSQL
- JDBC

## Architecture

Le projet respecte l'architecture demandée dans le cahier des charges :

- entities
- repository
- service
- view
- config
- exceptions

## Fonctionnalités

- Authentification
- Gestion des catégories
- Gestion des produits
- Gestion du stock
- Gestion des commandes
- Gestion des paiements
- Statistiques
- Gestion des utilisateurs internes
